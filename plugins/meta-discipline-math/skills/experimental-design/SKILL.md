# Experimental Design

The discipline of making a comparison mean something *before* the data arrive. Most fatal
errors in empirical work — confounding, pseudoreplication, unanswerable questions — are
committed at design time and cannot be repaired by any later analysis, however
sophisticated. Competence here is refusing to collect data whose error structure,
identifiability, and inference domain have not been written down first.

## Method

1. **State the question and its domain of inference.** What population of units and
   contexts must the conclusion generalize to? Write the "generalizes to" clause now;
   claims beyond it are extrapolation and will be labeled as such.
2. **Identify the experimental unit** by the assignment-independence test: the smallest
   entity to which a treatment is assigned *independently and at random*. Distinguish it
   from the observational unit (where measurement happens). **n is the number of
   independent units** — never the number of measurements. Subsamples are averaged per
   unit or modeled as a nested stratum; repeated measures on one unit share one
   randomization degree of freedom.
3. **Apply Fisher's triad**, each solving a distinct problem: *replication* (true
   replicates supply the error estimate — without them the F-test has no denominator),
   *randomization* (makes errors independent and justifies the inference; generated by a
   seeded, versioned, re-runnable procedure — "haphazard" is not random), *local
   control* (blocking removes known heterogeneity: blocks compact and oriented
   perpendicular to the dominant gradient, so variability falls between blocks, not
   within).
4. **Choose the design from the heterogeneity structure and the operational
   constraints** — there is no best design in the abstract:
   - homogeneous environment only → completely randomized;
   - one gradient → randomized complete blocks; two orthogonal gradients → row-column /
     Latin square;
   - many treatments vs small block capacity → resolvable incomplete blocks (lattice,
     alpha), software-generated with a reported efficiency factor; check the parameter
     identities $bk = vr$, $\lambda(v-1) = r(k-1)$, $b \ge v$ — non-integer λ means
     partially balanced, and treatment means must then be *adjusted*, never raw;
   - a hard-to-change factor → split-plot strata (the coarse factor pays with the
     coarser error); both factors large-scale → strip-plot (the interaction gains
     precision instead);
   - interactions are the question → factorial, with any confounding *declared*:
     generators, defining relation, and resolution stated before data — a confounded
     contrast is destroyed, not deferred;
   - a continuous, adjustable factor → response-surface design (replicated centre
     points for pure error and lack-of-fit) — model the curve, don't rank the doses;
   - conclusions must hold across contexts (sites, years, labs, cohorts) → replicate
     the experiment across contexts and treat context as random; more contexts with
     fewer replicates beat one context with many.
5. **Enumerate the error strata before data exist.** Write the table *factor →
   randomization unit → error term*: every level at which assignment was independently
   randomized is a stratum, and every effect is tested against the error of its own
   stratum. The degrees-of-freedom ledger closes exactly to N−1.
6. **Check identifiability.** No factor of interest may be a deterministic function of
   another factor or of the schedule (a phase × period table with empty cells is an
   alias). What the design confounds, no model, prior, or algorithm can later separate:
   break the determinism, measure the confounded cause directly, or declare the alias
   and shrink the claim.
7. **Size the study a priori** from four ingredients: δ (the minimum difference of
   *practical* interest, justified from the domain — never fished from data), σ (with
   its source), α, and the target power. Fix three, solve the fourth. Dependence within
   units is priced by the design effect $1 + (m-1)\rho$. Power is designed, not
   observed: post-hoc power is a tautology and is banned.
8. **Freeze the plan.** Data schema (tidy: one column per variable, one row per
   observation, one table per unit type), analysis model, and comparison plan are
   dated and fixed before the first observation; later changes are labeled amendments.

## The rigor standard (what "done right" means)

- **The model is a transcription of the randomization** — every stratum appears, none is
  invented; a reviewer can derive the analysis from the design ledger alone.
- **The randomization has a receipt**: seed + generator + versions regenerate the layout
  exactly.
- **Every question asked is answerable by construction**: no aliased contrast is among
  the stated objectives.
- **Precision is allocated deliberately**: the layout makes the primary contrast the
  precise one, and the design memo says so.
- **The inference domain is explicit**, and the number of contexts — not the number of
  units — carries generalization.

## Checkable output

End with a **design ledger**, fixed and dated before data collection:

```
ELEMENT            DECLARED                                    EVIDENCE
question / domain  response to treatment; units of type U,     "generalizes to" clause
                   contexts sampled from C
experimental unit  plot (treatment assigned per plot)          assignment-independence test
replication        r = 4 true replicates; m = 10 subsamples    n = 24 units; deff 1+(m−1)ρ
randomization      seeded permutation within block             seed + script regenerate layout
design             RCBD, blocks ⊥ dominant gradient            gradient sketch vs layout
error strata       block → (1|block); unit residual            df ledger: 3+5+15 = 23 ✓
identifiability    phase × period table complete               no empty cells
sizing             δ, σ (sourced), α, power → r                dated sizing note
```

A study ships only when every row has evidence. The ledger feeds
[[skills/statistical-inference/SKILL|statistical-inference]] directly: its stratum table
becomes the model's random part.

## Anti-patterns (reject these in review)

- Subsamples, or repeated measures on one unit, counted as replicates (inflated df,
  deflated SE, false positives — the cardinal error).
- Unseeded or "by eye" allocation presented as randomization.
- Blocks laid along the gradient instead of across it.
- Two randomization levels analyzed with one error term.
- Power computed after the data ("observed power"), or δ chosen by looking at the effect.
- A confounded effect reported as "not significant" instead of "not estimable (by design)".
- One giant equal-precision factorial where a screen → augment → optimize sequence was
  available.
- Conclusions asserted beyond the randomized or sampled domain without an extrapolation
  label.
