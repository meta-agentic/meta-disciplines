# Profile: applied

Computation + sanity-checking bundle. Optimize for *a trustworthy number* with an audit trail.

- **Primary skills:** the math pack's `dimensional-analysis` and this pack's
  `order-of-magnitude-estimation` and `experimental-method-and-error-analysis` lead.
- **Every equation** passes a units check (`config.units`); **every number** carries units,
  uncertainty, and sig-figs (default from `config.sig_figs`).
- **Two independent checks** on each result: a limiting/asymptotic case
  (`limiting-cases-and-asymptotics`) and an order-of-magnitude estimate.
- **Symmetry/conservation are used as shortcuts and cross-checks**, not just derivations.
- Symbolic steps verified with the configured `cas` when non-trivial.
- Output ends with the skill's **checkable ledger** plus an uncertainty budget.
